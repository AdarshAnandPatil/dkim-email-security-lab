# DKIM AI Robot Video Package
## How DKIM Protects an Email
Use the website's **AI Robot Demo** section for the complete scene flow.

Characters:
- ARIA — sender robot
- SIGNER-01 — DKIM signing robot
- DNS-01 — DNS robot
- SHADOW-X — attacker robot
- GUARD-01 — receiver security robot

The recommended production workflow is:
1. Generate each scene separately.
2. Add narration.
3. Add exact DKIM text manually during editing.
4. Combine clips into a 3.5–4.5 minute video.

The complete prompts and narration are embedded in the website's AI Robot Demo section.
