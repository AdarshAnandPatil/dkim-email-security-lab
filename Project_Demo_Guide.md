# Live Project Demo Guide
1. Open **DKIM Simulator**.
2. Enter domain, selector, subject and message.
3. Click **Sign & Send**.
4. Explain SHA-256 body hash, signature and DNS record.
5. Show **DKIM = PASS**.
6. Open **Attack Simulation**.
7. Modify the received message.
8. Click **Verify Modified Email**.
9. Show **DKIM = FAIL** and explain tampering detection.
