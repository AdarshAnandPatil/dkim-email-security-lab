# DKIM Email Security Lab V2

Interactive CNS seminar project.

Features:
- DKIM theory and email threats
- Animated DKIM security-bot story
- Canonicalization
- SHA-256 signing concept
- DKIM signature explorer
- DNS public-key lookup simulation
- PASS/FAIL and tampering simulation
- Header analyzer
- 15-minute seminar plan

## Run
npm install
npm start

## Render
Build Command: npm install
Start Command: npm start
Environment Variables: None
