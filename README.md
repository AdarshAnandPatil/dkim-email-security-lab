# DKIM Email Security Lab V3

Interactive Computer & Network Security seminar project.

## Features
- Colorful responsive UI
- DKIM Theory
- 25-slide interactive seminar presentation
- Previous/Next presentation controls
- DKIM signing and SHA-256 simulation
- DNS public-key simulation
- Attack/tampering simulation
- PASS/FAIL demonstration
- AI Robot Video page and timeline
- Project information

## Run locally
```bash
npm install
npm start
```
Open `http://localhost:3000`

## Render
Build Command: `npm install`
Start Command: `node server.js`
