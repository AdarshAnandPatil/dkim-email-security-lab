# DKIM Email Security Lab V3
CNS seminar project: **DomainKeys Identified Mail (DKIM)**.

## Features
- Home and DKIM theory
- AI Robot Demo package with scene-by-scene narration
- Interactive DKIM signing simulation
- Tampering attack simulation
- PASS / FAIL verification
- Seminar PPT content and presentation timeline
- Project demo guide

## Run locally
```bash
npm install
npm start
```
Open `http://localhost:3000`.

## Render
Build Command: `npm install`
Start Command: `npm start`
Environment Variable: none required (`PORT` is supplied by Render).
