# DKIM Seminar Project Package

## DomainKeys Identified Mail (DKIM): Email Authentication and Security

This package contains the complete material for a 15-minute CNS seminar.

## Contents
1. `DKIM_PPT_Content.md` — 25-slide presentation content with speaker notes and timing
2. `AI_Video_Scene_Plan.md` — 16-scene AI robot video plan with narration and prompts
3. `Project_Demo_Guide.md` — exact live demonstration steps
4. `Seminar_Timeline.md` — 15-minute presentation flow
5. `dkim-email-security-lab-v2/` — deployable interactive project

## Project Features
- Animated DKIM story
- Email signing simulation
- Canonicalization explanation
- SHA-256 concept
- DKIM signature explorer
- DNS public-key simulation
- PASS/FAIL simulation
- Tampering attack simulation
- Header analyzer for SPF/DKIM/DMARC result text

## Render
Build Command: `npm install`
Start Command: `npm start`
Environment Variables: None

PPT → AI Robot Video → Live Project Demo → Conclusion
