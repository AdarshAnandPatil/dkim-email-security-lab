📚 DKIM Theory

📧 What is DKIM?

DKIM is an email authentication method that uses cryptographic signatures.

🔑 Private Key

The sending domain uses a private key to sign selected email data.

🌐 DNS Public Key

The corresponding public key is published using a DNS DKIM record.

🛡️ Verification

The receiver retrieves the public key and checks the signature.

🎯 Strategy

Sign selected content, publish verification material, and allow receivers to detect changes.

⚠️ Note

DKIM is strongest when combined with SPF and DMARC policies.
